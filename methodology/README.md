# Methodology

Save the frozen methodology memorandum here as `methodology_v0.1.pdf`
(export it from the design document), and commit it **before** running
back-test B5 on real data. The commit date is the record that B5 was a
held-out test of a method fixed in advance.

When the method changes, save `methodology_v0.2.pdf` alongside it, note the
change and its reason in `CHANGELOG.md`, and tag the release.
